# Eduardo-Final-Project

The main objective of this application is to provide pet owners with a quick assessment of their dog's health status based on its breed and current weight. By selecting a dog breed and entering its weight, the program compares the user's input against standard veterinary reference weight ranges. It then calculates whether the dog is within a healthy range, overweight, or underweight, and explicitly displays by how much the dog deviates from its ideal weight.
